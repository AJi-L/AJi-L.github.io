### 概念认识

- 接口和标准

  - RJ45

    - RJ45是我们平时家用以太网的标准和接口，既是一个标准也是一个接口类型；

  - T1：车载以太网核心的物理层标准代号，T代表双绞线，1代表1对；100BASE-T1达标100兆基带单对双绞线以太网，1000BASE-T1则是1000M等；基本常用的接口是**罗森博格H-MTD接口**和**泰科MATEnet接口**；

  - 罗森博格H-MTD接口

    ![](/images/car-ethernet-switch/1570515468385E6K104-1XXZ5-Y.jpeg)

    - 泰科MATEnet接口

      ![](/images/car-ethernet-switch/ABUIABACGAAgrbjoyQYogqL2uQMwoAY4oAY%21400x400.jpg)

- 主从模式

  普通家用以太网（RJ45）是不区分主从的，但是车载以太网需要区分主从；但是车载以太网是由主从之分的（master & slave），从端跟随主端的节拍（时钟）进行数据传输；

  > 需要主从配置的原因：
  >
  > - 需要同时节省成本 使用1对双绞线 + 全双工 --> 一收一发已占用一对双绞线 --> 实现全双工需要在传输上面想办法 --> 首先需要时钟同步 --> 时钟只能是其中一个来源，另外一方去适配 --> 衍生出主从配置、加扰解扰器等

- 速率配置

  车载以太网有多种速率等级，有100M、1000M、10000M等等；

### 交换机连接

1. 咨询项目的以太网工程师，得到每个接口的接口定义（因为有多个接口）、以太网拓扑结构、主从模式、速率配置；
2. 集齐所需线束，如罗森博格接口的线束、RJ45网线（因为要连接电脑）；
3. 连接好板子、网线、交换机（转换器）、电脑；
4. 交换机一般有提示灯，灯亮则说明配置和连接OK；

### Windows电脑配置

```shell
:: ========================================================================
:: 网络调试笔记：电脑(A0) -> Android(中转) -> QNX
:: 拓扑关系：电脑(192.168.1.100) -> Android(192.168.1.100 | 192.168.1.100) -> QNX(192.168.1.100)
:: ========================================================================

:: 1. 配置电脑自身 IP 和掩码（建立电脑与 Android 的物理连接）
:: 参数含义：name=[本地网卡名称] static [电脑本机IP] [子网掩码]
:: 作用说明：将电脑IP设为 6.100，使其与 Android 的 6.3 处于同一网段，打通“电脑-Android”链路
netsh interface ip set address name="以太网 3" static 192.168.1.100 255.255.255.0

:: 2. 添加永久静态路由（实现电脑跨网段访问 QNX）
:: 参数含义：-p(永久有效,重启不丢失) add [目标QNX网段] mask [子网掩码] [下一跳网关,即Android的6系IP]
:: 作用说明：告诉电脑，凡是访问 192.168.1.X (QNX) 的数据，全部丢给 192.168.1.100 (Android) 处理
route -p add 192.168.1.100 mask 255.255.255.0 192.168.1.100

:: ========================================================================
:: 网络调试笔记：电脑(192.168.1.100) -> QNX
:: 拓扑关系：电脑(192.168.1.100) -> QNX(192.168.1.100)
:: ========================================================================
:: 配置ip为192.168.1.100
:: 配置ip为192.168.1.100
:: 参数含义：name=[本地网卡名称] [追加的第二个IP地址] [子网掩码]
:: 作用说明：给“以太网 3”追加 1.100 这个 IP，使其直接具备 1.X 网段身份，不再需要上面的路由命令
netsh interface ip add address name="以太网 3" 192.168.1.100 255.255.255.0

```

### Ubuntu电脑配置

```bash
##### ========================================================================
##### Linux 网络调试笔记（基于 ip 与 nmcli 命令）
##### ========================================================================

##### 1. 查看设备与当前网络信息
# 常用查看命令（二选一）：
# ifconfig 或 ip addr show enx607d095dd2cd
ifconfig
# 输出示例解析：
# 网卡名称: enx607d095dd2cd
# 当前IP : 192.168.1.100  子网掩码: 255.255.255.0 (/24)

##### 2. 临时配置（即时生效，重启电脑后失效）

# 【添加跨网段静态路由】
# 作用：告诉系统，去往 192.168.1.X 网段的数据，通过本地网卡经由网关 192.168.1.100 中转
# 参数：add [目标网段/掩码位] via [下一跳网关] dev [网卡名称]
sudo ip route add 192.168.1.100/24 via 192.168.1.100 dev enx607d095dd2cd

# 【删除指定IP地址】
# 参数：del [要删除的IP/掩码位] dev [网卡名称]
sudo ip addr del 192.168.1.100/24 dev enx607d095dd2cd

##### 3. 持久化配置（NetworkManager 管理，重启不丢失）

# Step 1: 创建新连接
# 作用：创建一个名为 my-static-ip 的网络连接配置，并绑定到物理网卡，同时指定静态IP
# 参数：con-name [自定义连接名] ifname [物理网卡名] ip4 [静态IP/掩码位]
sudo nmcli connection add type ethernet con-name my-static-ip ifname enx607d095dd2cd ip4 192.168.1.100/24

# Step 2: 激活连接
# 作用：启动刚创建的配置，使其立刻在网卡上生效
sudo nmcli connection up my-static-ip

# 【后续修改IP】
# 作用：当需要将已有的静态IP修改为其他地址时使用
# 参数：modify [连接名] ipv4.addresses [新IP/掩码位]
sudo nmcli connection modify my-static-ip ipv4.addresses 192.168.1.100/24

# 【刷新配置】
# 作用：修改IP后，必须重新激活连接才能将新IP应用到网卡
sudo nmcli connection up my-static-ip

# 修改连接为 dhcp 模式
sudo nmcli connection modify my-static-ip ipv4.method auto
# 重新激活生效
sudo nmcli connection up my-static-ip
```
